# Loan-Approval-and-Risk_Score
Machine learning and deep learning project for loan approval classification and risk score prediction.
## Project Overview
This project predicts loan approval and risk score using machine learning and deep learning models.
## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow
- Seaborn
## Models Used
### Loan Approval Classification
- Logistic Regression
- Gaussian Naive Bayes
- SVM
- Decision Tree
- Random Forest
- Neural Network
### Risk Score Regression
- Linear Regression
- SVR
- Decision Tree Regressor
- Random Forest Regressor
- Neural Network
## Results
The classification models were evaluated using accuracy and confusion matrix.
The regression models were evaluated using R-squared and Mean Absolute Error (MAE).
The Neural Network showed balanced performance for the Risk Score prediction.

## Key Learning
This project helped me understand data preprocessing, PCA, classification, regression, model evaluation, and neural networks.
